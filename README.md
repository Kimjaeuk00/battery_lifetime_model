# ESS 배터리 수명 예측

초기 100사이클에서 관측한 방전 곡선 변화, 방전 용량 변화, 평균 온도로 배터리의 최종 수명(`cycle_life`)을 예측합니다.

## 프로젝트 개요

- 데이터셋: MIT-Stanford Battery Dataset — Severson et al., _Nature Energy_ (2019)
- 학습·검증 데이터: Batch 1 (`2017-05-12`), 46개 셀
- 평가 데이터: Batch 2 (`2018-02-20`), 원본 47개 중 수명값이 없는 8개를 제외한 39개 셀
- 태스크: **Regression — 최종 Cycle Life 예측**
- 입력 변수: `delta_q_min`, `QD_change_10_100`, `mean_Tavg`
- 최종 모델: **RBF-SVR`{'C': 61901.9925067011, 'gamma': 0.003358414074222409, 'epsilon': 3.074011265778389}`**
- 최종 성능: `Batch 2 테스트 MAPE: 18.63%`

### 열화 곡선 분석

전체 방전 용량 곡선에서는 초기 변화가 작다가 후기 구간에서 감소가 빨라지는 형태가 관찰됩니다. 초기 용량이 비슷한 셀도 이후 열화 경로와 최종 수명은 달라지므로, 초기 방전 용량의 절대값만으로 수명을 구분하기에는 한계가 있습니다.

후기 급격한 감소 구간은 knee point와 부합하는 형태지만, Knee point가 100 사이클 이상에 나오는 경우도 빈번하므로 변수로 활용하기엔 제한적입니다. 이를 대신해 QD 값의 기울기, 변화량을 변수로 선정했습니다.

**핵심 발견:** 100사이클의 한계를 고려해 Knee point 대신`QD_change_10_100`, `QD_slope_10_100`을 변수 후보로 선정했습니다.

### ΔQ(V) 곡선 분석

동일한 전압 격자에서 `ΔQ(V) = Q100(V) − Q10(V)`를 계산했습니다. EDA에서는 약 3.0V 부근에서 장·단수명 셀의 차이가 두드러지는 형태를 확인했고, 곡선을 셀별 숫자로 요약하기 위해 최솟값·평균·분산을 비교했습니다.

Batch 1에서 `delta_q_min`과 수명의 Pearson 상관계수는 **0.882**였습니다. Batch 1의 `delta_q_min`은 모두 음수이며, 이 양의 상관은 최솟값이 덜 음수인 셀일수록 수명이 긴 경향을 의미합니다. `delta_q_min`과 `delta_q_mean`의 상관은 0.993, `delta_q_min`과 `delta_q_var`의 상관은 −0.974로 정보가 크게 겹쳤습니다.

**핵심 발견:** 전압별 용량 변화를 대표하는 변수 후보로`delta_q_min, delta_q_mean, delta_q_var`을 선택했습니다.

### 충전 속도(C-rate)와 수명의 관계

EDA에서는 2단계 충전 프로토콜을 파싱하고, 0~80% SOC 구간의 등가 충전 속도별 평균 수명을 비교했습니다. Batch 1에서는 빠른 충전 정책에서 수명이 짧아지는 경향이 나타났지만, 다른 배치의 수명 차이를 충전 속도만으로 설명하기는 어려웠습니다. 정책당 셀 수도 적으므로 관찰된 관계를 인과관계로 확정하지 않습니다.

**핵심 발견:** Batch 1에서만 유의미한 변수로, 과적합을 방지하기 위해 `C_rate`는 모델링 시 변수 후보에서 제외했습니다.

### 특징 간 상관관계

Batch 1 내에서의 변수 12가지에 대한 상관계수를 파악했습니다. 파생 변수 중에서는 결과값과 상관계수가 높은`delta_q_min`, `QD_change_10_100`2가지를 선택하고, 다중공선성을 고려해 나머지 변수는 모델링에서 제외했습니다. 기존 변수 7가지 중에서는 상관계수가 높은 `mean_Tavg`를 선정했습니다.

세 변수는 전압별 방전 곡선 변화, 사이클별 총 방전 용량 변화, 초기 열적 조건을 각각 나타냅니다. 46개라는 작은 표본을 고려해 최소한의 변수를 선정했습니다. `delta_q_min`와 `QD_change_10_100`은 초기의 방전 용량을 얼마나 잘 유지할 수 있느냐에 대한 지표이고, `mean_Tavg`는 온도로 인한 부반응을 유발해 열화에 영향을 줄 수 있는 지표입니다. 따라서 3가지의 변수는 부반응을 유발할 수 있는 환경에 대한 변수와 실제 성능 저하를 포함하는 것으로, 배터리의 수명을 예측할 수 있는 변수들입니다.

## Modeling

### 피처 엔지니어링 전략

| 피처               | 계산 방법                                                     | 선정 근거                                    |
| ------------------ | ------------------------------------------------------------- | -------------------------------------------- |
| `delta_q_min`      | 10·100회차`Qdlin` 곡선 차이의 최솟값: `min(Q100(V) − Q10(V))` | 수명과 강한 상관을 보인 전압별 변화의 대표값 |
| `QD_change_10_100` | `QDischarge100 − QDischarge10`                                | 초기 방전 용량의 변화량을 표현               |
| `mean_Tavg`        | 2~100회차`summary.Tavg` 99개 값의 산술평균                    | 초기 사이클의 열적 조건을 표현               |

수명값이 없는 Batch 2의 8개 셀은 정답과 비교할 수 없어 평가 대상에서 제외했습니다.

학습·검증 데이터는 Batch 1에서 Train 80%(35개), Hold-out 20%(11개)로 분리했습니다. 같은 충전 프로토콜의 셀이 양쪽에 섞이지 않도록 `GroupShuffleSplit(test_size=0.20, random_state=42)`을 사용했습니다.

학습 데이터 내부에서는 `CV_FOLDS = 5`로 설정하여 `GroupKFold` 기반 교차검증을 수행했습니다. 이때 평균 MAPE를 기준으로 모델과 하이퍼파라미터를 선택했으며, Hold-out은 교차검증에 포함하지 않았습니다.

### 모델 선택 및 근거

- **중앙값 기준선:** 입력을 사용하지 않고 학습 수명 중앙값을 예측하여 모델의 개선 여부를 판단합니다.
- **선형회귀:** 적은 표본에서 단순한 선형 관계의 기준 성능을 확인합니다.
- **Ridge:** 가중치 크기를 규제하여 서로 연관된 특징을 사용할 때의 안정성을 확인합니다.
- **Huber:** 큰 잔차의 영향을 완화하는 선형 모델과 비교합니다.
- **RBF-SVR:** 변수 3개와 수명의 관계를 비선형으로 표현했을 때의 개선 여부를 확인합니다.

최적화에는 **Optuna TPE**를 사용했습니다. 초기 10회 이후에는 이전 CV 결과를 활용하여 범위 안의 다음 파라미터 값을 제안합니다. Ridge·Huber·SVR을 각각 **500회** 탐색하며, 매 시도마다 같은 5개 그룹 분할의 평균 MAPE를 최소화합니다. 난수 시드는 42, 실행은 순차 방식으로 고정했습니다. 기준선과 선형회귀는 별도의 파라미터 탐색 없이 같은 CV에서 평가했습니다.

최종 저장 코드의 탐색 범위는 다음과 같습니다.

| 모델    | 탐색 범위                                                                                          |
| ------- | -------------------------------------------------------------------------------------------------- |
| Ridge   | `alpha`: 0.0001부터 1,000까지, 로그 척도                                                           |
| Huber   | `alpha`: 0.00001부터 10까지, 로그 척도 / `epsilon`: 1.0부터 3.0까지                                |
| RBF-SVR | `C`: 1부터 200,000까지, 로그 척도 / `gamma`: 0.0001부터 1까지, 로그 척도 / `epsilon`: 1부터 10까지 |

저장된 교차검증 결과는 다음과 같습니다. 표준편차는 fold별 MAPE의 변동을 나타내며 신뢰구간은 아닙니다.

| 모델          | CV 평균 MAPE (%) | CV 표준편차 (퍼센트포인트) |
| ------------- | ---------------: | -------------------------: |
| **RBF-SVR**   |         **7.65** |                       2.39 |
| Huber         |             8.28 |                       2.53 |
| Ridge         |             8.32 |                       2.58 |
| 선형회귀      |             8.95 |                       1.55 |
| 중앙값 기준선 |            19.63 |                       9.15 |

**최종 모델은 RBF-SVR**이며, 파라미터는 `C=61901.9925067011`, `gamma=0.003358414074222409`, `epsilon=3.074011265778389`입니다. 학습 데이터 CV 평균 MAPE가 가장 낮아 선택했습니다.

| 구분                     | MAPE (%) / Gap (퍼센트포인트) | 비고                                                |
| ------------------------ | ----------------------------: | --------------------------------------------------- |
| Train (Batch 1 CV)       |                          7.65 | 학습 35개 셀의 그룹 교차검증 평균                   |

### 원인 가설 및 개선 방향

- **단수명 학습 사례 부족:** Batch 1의 최소 수명은 534사이클로 Batch 2 단수명 구간의 정답을 직접 학습하지 못했습니다. 학습 범위를 벗어난 예측이기에 기존보다 예측 성능이 떨어졌습니다.
- **입력·운영 조건의 분포 차이:** 배치 간 수명 및 특징 범위가 다르고 일부 프로토콜의 반복 셀에서 오차가 큽니다. 초기 3개 변수만으로 포착하지 못한 실험 조건이나 셀 차이가 남아 있을 가능성이 있습니다.

후속 개선에서는 추가 학습 배치와 단수명 사례를 확보하고, 동일한 특징 정의로 배치별 오차를 검증하는 것이 우선시 하겠습니다.

## ESS 도메인 해석

### 실제 BESS 운영에서 활용 가능한 의사결정

- **초기 셀 선별과 품질 관리:** 초기 관측에서 상대적으로 수명이 짧을 것으로 예상되는 셀의 추가 검사 우선순위를 정합니다.
- **점검·교체 계획 보조:** 예상 수명을 참고하여 정밀 점검과 예비품 확보의 우선순위를 정합니다.
- **운영 정책 비교 보조:** 같은 정의의 특징을 확보할 수 있는 조건에서 충전 정책별 예상 수명을 비교하는 탐색 지표로 활용합니다.

### 개발 한계와 실 배포에 필요한 사항

1. **실험실 셀과 현장 시스템의 차이:** 급속 충전 LFP/흑연 셀의 예측을 다른 화학계, 모듈·팩 또는 ESS 운전 조건에 그대로 적용할 수 없습니다. 온도, SOC 범위, 충방전율, 셀 간 불균일성과 캘린더 열화를 포함한 현장 검증이 필요합니다.
2. **관측 및 특징 확보 조건:** 100사이클과 동일 전압 격자의 방전 곡선이 필요합니다. 부분 충방전이 많은 ESS에서 동일한 입력을 만들 수 있는지, 센서·BMS 데이터의 품질과 수집 주기를 확인해야 합니다.
3. **Cycle Life와 RUL의 차이:** 출력은 초기 데이터로 예측한 최종 수명입니다. 현재 상태에서의 잔여 수명(RUL), 달력상 잔여 기간, 고장 확률을 직접 추정한 것은 아닙니다.
4. **표본 수와 불확실성:** 학습에 35개 셀만 사용했으며 예측 구간이나 불확실성은 산출하지 않았습니다. 현장 활용 전에는 더 많은 독립 셀·배치에서 오차와 과대예측 위험을 확인해야 합니다.
5. **재현 및 배포 준비:** 의존성 버전 고정, 원본 데이터 버전·정제 기준 기록, 모델과 표준화 객체 저장, 입력 품질 검사, 예측 이력 및 분포 변화 모니터링이 필요합니다. 현재는 노트북 기반 개발 결과이며 운영 시스템으로 배포되지 않았습니다.
